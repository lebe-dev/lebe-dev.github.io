Ранее я уже описывал ряд проблем с субтитрами, а потом пришла идея. Почему бы не создать субтитры из дорожки дубляжа?

Как только выходит новый фильм, зачастую к нему поспевает дубляж на всех популярных языках. С субтитрами всё обычно печальней: их может не быть даже спустя десятилетие после релиза.

У этого метода есть два больших преимущества. Первое — не нужно подгонять субтитры к версии фильма (театральная, режиссёрская и так далее). Второе — переводить слова не требуется, это сделал живой человек, и он учёл контекст фильма. Например, при переводе английских субтитров на любой другой язык нужно давать контекст, иначе слова будут переведены неправильно: в средневековом контексте значение слова «suffer» — позволять, дозволять, допускать, а современное — страдать.

Что нужно для перевода

Ниже дан список того, что потребуется, но главное из этого — доступ к LLM и агентский софт (Claude Code, Codex, opencode и так далее): агент сделает всё необходимое.

  • Утилита ffmpeg для извлечения аудиодорожки с дубляжом из видео
  • OpenAI Whisper Large v3 (локальная версия модели) для транскрибации аудиодорожки. Для её запуска не нужна мощная видеокарта, достаточно обычного процессора
  • Утилита submarine для проверки целостности итоговых субтитров
  • Файл с фильмом. Например, Movie.mkv.

Извлечение дорожки дубляжа

Обычно аудиодорожки хранятся внутри видеофайла (контейнера), а нам нужно достать ту, что с дубляжом.

Промпт будет такой:

Промпт
Извлеки из файла Movie.mkv с помощью ffmpeg все аудиодорожки и сложи рядом

Далее запускаем полученные аудиофайлы и ищем тот, где наша родная речь.

Создание субтитров

Далее — в агенте сбрасываем контекст, ставим Medium или High Effort и запускаем промпт, который сделает оставшуюся часть работы:

Промпт
Используй Whisper Large v3 для транскрибации аудиодорожки из файла movie.mp3 и 
на выходе создай файл в формате субтитров (srt). Для Whisper Large v3 используй 
whisper.cpp (сборку с поддержкой Metal-GPU), запуск через whisper-cli.

Для проверки целостности субтитров используй 
утилиту submarine (https://github.com/lebe-dev/submarine).

## Нюансы

- **mlx-whisper не подходит**: beam search в нём не реализован
  (`NotImplementedError`), только greedy. whisper.cpp даёт и beam search,
  и Metal-GPU.
- **`-mc 0` обязателен.** Это нулевой текстовый контекст, главная защита от
  зацикливания. С полным контекстом модель на первой же длинной паузе
  выдала текст самого промпта. С `-mc 64` пунктуация красивее (3% реплик без
  знаков против 22%), но теряется **23% слов** и втрое больше повторов —
  полнота важнее.
- **`--prompt` при `-mc 0` бесполезен**: урезается до 1 токена, в логе видно
  предупреждение. Пунктуацию модель ставит и без него.
- **VAD (`--vad` + Silero) не включать.** Титровые галлюцинации убирает, но
  выкидывает реальные фразы (137 на фильм) и сам зацикливается. В окнах, где
  основной прогон галлюцинировал, реальной речи не оказалось — терять нечего.
- **`-dtw` требует `-nfa`**: с flash attention (включено по умолчанию) все
  `t_dtw` возвращаются как `-1`.
- Запускать `whisper-cli` в фоне только через `run_in_background`, без
  `nohup ... &` — иначе процесс убивается вместе с обёрткой.

## Дополнительно

Если найдёшь какие-то нюансы в процессе работы, запиши их себе.

По окончании работы агент создаст файл вида movie.srt:

Добро пожаловать на факультет,
профессор Вонг.

9

Спасибо.

10

- Будем!

Субтитры готовы к употреблению.
