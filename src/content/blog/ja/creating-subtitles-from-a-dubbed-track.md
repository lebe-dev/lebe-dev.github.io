以前に[字幕まわりのいくつかの問題](/ja/blog/how-i-translate-subtitles-with-llm/)について書きましたが、そのあとで思いつきました。吹き替え音声から字幕をつくればいいのでは？

新作映画が公開されると、主要な言語の吹き替えはたいてい早い段階で出てきます。字幕のほうはもっと悲惨で、公開から10年たっても存在しないことすらあります。

この方法には大きな利点が二つあります。一つ目は、映画のバージョン（劇場版、ディレクターズ・カットなど）に合わせて字幕のタイミングを調整する必要がないこと。二つ目は、翻訳そのものが不要なこと。すでに人間が訳していて、しかも作品の文脈をふまえています。たとえば英語字幕を他の言語に訳す場合、文脈を渡さないと単語の訳を間違えます。中世の文脈では「suffer」は「許す、容認する」の意味ですが、現代の意味は「苦しむ」です。

## 必要なもの

必要なものを下に挙げますが、いちばん重要なのは LLM へのアクセスとエージェント系のソフト（Claude Code、Codex、opencode など）です。残りはエージェントがやってくれます。

- 動画から吹き替え音声トラックを抽出するための [ffmpeg](https://github.com/ffmpeg/ffmpeg)
- 音声トラックを文字起こしするための [OpenAI Whisper Large v3](https://github.com/openai/whisper)（モデルのローカル版）。実行に強力な GPU は不要で、普通の CPU で足ります
- できあがった字幕の整合性を検証するための [submarine](https://github.com/lebe-dev/submarine)
- 映画のファイル本体。たとえば `Movie.mkv`

## 吹き替えトラックの抽出

音声トラックは通常、動画ファイル（コンテナ）の中に入っていて、そこから吹き替えのものを取り出す必要があります。

プロンプトはこうです。

```prompt
ffmpeg を使って Movie.mkv からすべての音声トラックを抽出し、同じ場所に置いてください
```

そのあと、得られた音声ファイルを再生して、自分の母語が聞こえるものを探します。

## 字幕の作成

次に、エージェントのコンテキストをリセットし、Medium または High Effort に設定して、残りの作業をこなすプロンプトを実行します。

```prompt
Whisper Large v3 を使って movie.mp3 の音声トラックを文字起こしし、
出力として字幕形式（srt）のファイルを作成してください。Whisper Large v3 には
whisper.cpp（Metal-GPU 対応ビルド）を使い、whisper-cli 経由で実行してください。

字幕の整合性チェックには submarine
（https://github.com/lebe-dev/submarine）を使ってください。

## 注意点

- **mlx-whisper は使えない**: beam search が実装されておらず
  （`NotImplementedError`）、greedy のみ。whisper.cpp なら beam search も
  Metal-GPU も使える。
- **`-mc 0` は必須。** テキストコンテキストをゼロにする指定で、ループに対する
  いちばんの防御になる。コンテキストを全部渡すと、最初の長い無音でモデルが
  プロンプトそのものを出力した。`-mc 64` にすると句読点はきれいになる
  （記号なしの行が 22% から 3% に）が、**単語の 23% が失われ**、繰り返しは
  3 倍に増える。網羅性のほうが大事。
- **`-mc 0` のときの `--prompt` は無意味**: 1 トークンに切り詰められ、ログに
  警告が出る。句読点は指定しなくてもモデルが付ける。
- **VAD（`--vad` + Silero）は有効にしない。** クレジット的な幻覚は消えるが、
  実際の発話まで捨ててしまい（1 本あたり 137 件）、それ自体がループする。
  メインの実行で幻覚が出た区間には実際の発話はなかったので、失うものはない。
- **`-dtw` には `-nfa` が必要**: flash attention（デフォルトで有効）だと
  `t_dtw` がすべて `-1` で返る。
- `whisper-cli` をバックグラウンドで動かすときは必ず `run_in_background` を使い、
  `nohup ... &` は使わないこと。ラッパーごとプロセスが落ちる。

作業が終わると、エージェントは `movie.srt` のようなファイルを作ります。

```

## もっと品質を上げたいなら

さらに品質を上げたい場合は、Wikipedia の英語版から映画のあらすじを渡すとよいです。

原語の字幕ファイルを横に置いておき、翻訳の品質を無作為に照合するようエージェントに頼むこともできます。
